00–05 MINUTES

Open the checked Lesson 2 data.

The policy question is: how do the income and under-five mortality patterns for one region compare with the complete all-countries sample during 2000–2022?

STUDENT SCAFFOLD

Open the complete Math Camp project in RStudio and work through code/lab-3-starter.R. It reads the checked Lesson 2 table from outputs/02-health-analysis.csv. Keep all of your code and written answers in this one file.

Complete and save Exercises 1–4 before opening Codex. The agent will read the same file containing your selected region, tables, figures, and initial interpretation.

Four outputs

  1. 01A description of the selected regional sample.
  2. 02Comparable all-countries and regional briefing tables.
  3. 03Comparable all-countries and regional figures.
  4. 04An independently written interpretation checked after saving.

05–14 MINUTES

Exercise 1: describe one region.

Inspect the documented region names and choose one. Filter health_panel once and keep that selection unchanged. Record the number of rows, economies, years, period, and missing values in regional_record.

CHECKPOINT 1

Explain what one row represents, whether every economy contributes the same number of years, and one coverage issue that could affect the regional comparison.

14–28 MINUTES

Exercise 2: construct two briefing tables.

The supplied all-countries table reports the number of contributing economies, median income, and median under-five mortality in 2000, 2010, and 2022. Adapt the same pipeline to regional_panel so that regional_briefing has the identical structure.

CHECKPOINT 2

Record one all-countries change, one regional change, and one reason the contributing economy counts matter for the comparison.

28–42 MINUTES

Exercise 3: visualize both patterns.

Recreate the Lesson 3 all-countries point cloud and then construct the same figure for regional_panel. Keep the variables, units, logarithmic scales, geometry, and visual treatment constant so that the sample is the central difference.

CHECKPOINT 3

Name one feature shared by the figures, one meaningful difference, and one conclusion neither figure can establish.

42–48 MINUTES

Exercise 4: write before opening Codex.

Work independently. Complete all_countries_claim, regional_claim, and comparison_note using your two tables and two figures. Name the sample, period, direction of the association, and at least one limitation.

Save the script. Codex cannot inspect changes that remain only in the RStudio editor.

48–57 MINUTES

Give the completed file to Codex.

Use the fixed prompt printed after Exercise 4. Codex reads the saved file, checks the sample and objects, fits one pooled log–log model for all countries and one for the selected region, and proposes two claims.

Select one material agent statement. Record the R object or calculation used to check it, then accept, revise, or reject the statement. Numerical reproduction and interpretation are separate checks.

57–60 MINUTES

Report the comparison and verification.

Share the main difference between the all-countries and regional briefings, one claim supported by the regional figure, and one Codex statement you checked.

  • □The same selected region appears in the data, table, figure, model, and sentence.
  • □The all-countries and regional briefings use comparable definitions.
  • □The final claims distinguish association from causation.
