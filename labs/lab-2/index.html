THE ASSIGNMENT

Income, health, and the observations behind a claim.

You are preparing background evidence for a policy briefing: How is national income associated with under-five mortality across economies between 2000 and 2022?

Before making a table, plot, or regression, you need a dataset that represents the question correctly. One row should represent one economy in one year. The analysis needs economy identifiers, region, current income classification, GDP per capita (PPP), under-five mortality, and a logged-income measure. Observations without usable income or mortality information should not enter this first descriptive analysis.

Your task is to set the analytical standard, commission the work, and decide whether the resulting evidence is defensible. Codex will first act as a verifier and then as the operator of a complete construction pipeline. Neither role makes the release decision for you.

THE CENTRAL RISK

A pipeline can execute successfully and satisfy a structural specification while relying on an arbitrary source or record rule. Correct output by accident is not a defensible method.

AUDIT + RELEASE DECISION

Test code, structure, and source fidelity separately.

Run the candidate-output audit after Codex finishes. Structural checks ask whether the file has the required columns, unique keys, period, observed values, and transformation. Source concordance asks whether keys and values agree with documented project data. Code review asks whether the method would remain defensible if row order or input contents changed.

LayerQuestionPossible failure
Generated codeAre source and record rules defensible?A keep-last rule happens to retain the right row.
File structureDoes the output satisfy its explicit specification?A plausible wrong value passes a range check.
Source concordanceDo keys and values match documented evidence?A clean-looking file contains unsupported values.
InterpretationWhat has the construction established?A checked dataset is treated as a causal result.

Finish with an actual decision: accept, revise, or reject. If the pipeline survives every test, identify the strongest failure you attempted to falsify and the evidence that ruled it out.

SIX CHECKPOINTS

The checkpoints demand a failure chain, adjudication of a verifier claim, review of the pipeline commission, a release decision from independent audits, a grouped briefing result, and a comparison of the two agent roles.
