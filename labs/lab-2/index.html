THE BRIEF

Let the agent build. Make the evidence earn your trust.

Choose one indicator from your track. The frozen 2000-2022 file remains untouched. Your task is to supervise an update, not to accept the newest file automatically.

STOP CONDITION

If the source changes, the key duplicates, the unit differs, or the agent cannot document the request, stop and preserve the failure as evidence.

35 MINUTES

Contract, build, inspect.

00-05Scope

Choose one indicator and define the expected output.

05-15Prompt

Give the agent the source, constraints, and done-when checks.

15-25Run

Review the proposed code before executing it.

25-35Inspect

Check keys, latest year, missingness, and retrieval date.

UPDATE CONTRACT
Extend one named World Bank indicator using the official API. Write a new dated output. Do not overwrite or silently revise the frozen file. Preserve the indicator code and unit. Add checks for unique country-year keys and report the latest available year.

15 MINUTES

New years are not the only change.

  • □How many genuinely new country-years were added?
  • □Did previously published values change?
  • □Did the missingness pattern change?
  • □Is the latest year the same for every country?
  • □Can someone rerun the API request from the saved code?
