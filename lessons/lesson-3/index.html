LEARNING OUTCOMES

Connect a visual pattern to a careful sentence.

By the end of the meeting, you should be able to create a legible comparison, fit a simple regression, inspect residuals, and state what the evidence does and does not show.

  1. 01Choose plot encodings that match the variables and question.
  2. 02Use transformations when the scale makes a pattern hard to see.
  3. 03Interpret a coefficient in the units of the variables.
  4. 04Inspect residuals and influential observations.
  5. 05Separate descriptive, associational, and causal language.

CLAIM LADDER

Use the strongest claim the design can carry.

LevelExampleAllowed here?
DescriptiveUnder-five mortality declined in most observed countries.Yes, with coverage noted.
AssociationalHigher income is associated with lower mortality in this sample.Yes, with specification noted.
CausalHigher income caused mortality to fall.No. This design does not identify a causal effect.
INTERPRETATION CHECK

A more complex model does not repair a weak research design. The purpose here is to learn the mechanics and limits of comparison before the fall sequence develops them further.

RFROM PLOT TO MODEL
ggplot(health, aes(log_income, under5_mortality,
                   color = income_level)) +
  geom_point(alpha = 0.45) +
  geom_smooth(method = "lm", se = FALSE)

fit <- lm(under5_mortality ~ log_income + income_level,
          data = health)
summary(fit)

The line summarizes a fitted relationship. It does not reveal the mechanism that produced it.

AGENT REVIEW PASS

Separate code review from statistical review.

STARTER PROMPT
Goal: Review this analysis in two separate passes.
Context: Read the policy question, variable dictionary, script, and generated figure.
Pass 1: Check code behavior, missing values, transformations, labels, and reproducibility.
Pass 2: Check whether the written claim matches the descriptive design and model output.
Constraints: Do not rewrite the analysis. Quote the exact evidence for each concern. Do not suggest causal language.
Done when: I have a short list of verified issues, uncertain issues, and checks I can run in R.
  • □Can every concern be tied to code, output, or documentation?
  • □Did the agent confuse prediction, association, and causation?
  • □Did you inspect at least one surprising observation yourself?
  • □Does the final sentence name a limitation?
