START WITH THE TABLE CONTRACT

What must one row represent?

Before touching a data verb, write the analysis table you need: the population, unit of observation, key, time period, outcome, comparison variable, and grouping variables.

Contract field Health example Why it matters
Population Countries and economies with observed indicators Defines who can appear in the analysis.
Unit Country-year Determines what one row means.
Key iso3c + year Must identify each row uniquely.
Period 2000–2022 Sets the comparison window.
Outcome Under-five mortality Names the quantity to describe.
Comparison GDP per capita, PPP Names the relationship of interest.

The contract gives the schema substantive meaning. If the unit changes from country-year to region-year, the question and interpretation change with it.

THE CONTRACT IS A MAP

A useful map is selective. The table contract keeps the choices needed for this policy question: who appears, what one row means, which period matters, and which relationship we plan to describe. The build record shows whether the R pipeline followed that map.

THE GRAMMAR OF DATA CONSTRUCTION

Six verbs, six kinds of decision.

Verb Question before running Evidence after running
select() Which variables and identifiers are necessary? Names and number of columns.
filter() Which observations leave the population? Rows, countries, and years before versus after.
mutate() What does the new variable mean and in what unit? Missingness, range, and a hand-checked example.
group_by() Which observations belong together? The active grouping variables.
summarise() What will one output row represent? Expected group count and unit.
left_join() Is the right-side key unique and should every left row match? Row count, duplicates, and unmatched keys.
PREDICTWhat should change?

Rows, columns, values, order, or unit.

RUNExecute one step.

Keep the pipeline small enough to inspect.

CHECKDid the expected change occur?

Use counts, keys, ranges, or anti-joins.

RECORDWhy should the step remain?

Leave the reason in code or documentation.

BUILD RECORD

Keep the source and the checks together.

Frozen source→Question sample→Derived variables→Metadata join→Analysis table→Build record

The frozen inputs stay unchanged. The script creates the analysis table from them. The build record reports row counts, the country-year key, year coverage, variable units, missingness, and unmatched joins. A figure or a table created at the end never becomes a new source file.

SUCCESSFUL EXECUTION NEEDS A STRUCTURE CHECK

R can complete a join with the wrong key, duplicated metadata, or unmatched countries. After the syntax runs, compare the expected structure with the observed rows, keys, and matches.

RHEALTH ANALYSIS TABLE 
library(tidyverse)

wdi <- read_csv(
  "data/derived/math-camp-wdi-2000-2022.csv",
  show_col_types = FALSE
)

health <- wdi |>
  select(
    iso3c, country, year, income_level_current,
    gdp_per_capita_ppp, under5_mortality
  ) |>
  filter(year >= 2000) |>
  mutate(log_income = log(gdp_per_capita_ppp))

stopifnot(!anyDuplicated(health[c("iso3c", "year")]))
stopifnot(all(health$year >= 2000))

select() makes the analytical scope visible. filter() defines the time window and therefore changes the represented sample. mutate() preserves the original income measure while adding a logged version whose interpretation must be explained. The assertions turn two structural expectations into executable checks.

BOUNDED ASSISTANCE

Let the agent improve a step you can already evaluate.

Use the agent as a supervised cleaning assistant after you can explain the pipeline. Delegate one bounded improvement such as adding assertions, diagnosing an unmatched join, or producing a compact build record.

Goal: Add a build record for the health analysis table.
Context: Read code/02-build-analysis.R and the indicator dictionary.
Permission: Propose an edit, but do not run it or change frozen data.
Constraints: Preserve the country-year unit and existing variable names.
Proof: The record must report input/output rows, unique keys, years, missingness in both indicators, ranges, and any failed condition.
