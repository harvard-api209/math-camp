LEARNING OUTCOMES

Know what you are looking at.

By the end of the meeting, you should be able to open a project, run R code, identify the unit of observation, inspect variables, and ask an agent for an explanation without surrendering the question.

  1. 01Distinguish R, RStudio, Quarto, and the coding agent.
  2. 02Describe one row and one column in plain language.
  3. 03Use glimpse(), count(), and summary() to inspect a dataset.
  4. 04Recognize missing values and implausible ranges.
  5. 05Ask Codex or Claude Code to explain a bounded piece of code.

Why this matters for policy work

Policy analysis often begins before a model is fitted. It begins when an analyst decides what one row represents, whether two columns can be compared, and which observations are absent. If those decisions remain vague, polished code can produce a precise answer to the wrong question. The first lesson therefore treats inspection as substantive work rather than a preliminary chore.

Coding agents raise the stakes. They can move across a project, draft code, and explain unfamiliar syntax much faster than a search-and-copy workflow. The same speed can also reproduce a mistaken unit, an implausible value, or an invented definition. A useful analyst must be able to pause the agent, locate the evidence, and decide what deserves trust. That habit is the foundation for every later lesson.

NO-AGENT CHECKPOINT

Run the starter script, change one country code, and predict the result before using an agent. This small step makes the boundary between R and AI visible.

AI LITERACY

A fluent collaborator can still be wrong.

An AI model generates a plausible continuation from patterns learned in data. A chatbot mainly responds in a conversation. A coding agent can also inspect files, propose a plan, run tools, edit code, and report results. That extra reach makes the agent useful, but it also makes supervision more important.

Codex
The baseline coding agent for camp. It can work with the files in a project, run bounded checks, and explain or edit code when authorized.
Claude Code
An alternative coding agent with a similar project-level workflow. Syntax and interface differ, but the supervision principles are the same.
Agentic workflow
A loop in which a human sets the goal and constraints, the agent proposes or executes steps, and the human verifies the evidence.
Hallucination
A confident statement, citation, function, or result that is unsupported or fabricated. Fluency is not verification.

Why use these tools in Math Camp?

They lower the cost of asking for explanations, make project-wide assistance possible, and expose a new professional skill: supervising computational work. We are moving beyond a closed demonstration studio because analysts increasingly work in systems where code, documentation, and AI assistance share the same project. The goal is not to outsource learning. The goal is to learn how to direct, inspect, and challenge the tools students will encounter.

  • □Keep private, restricted, and identifiable data out of public AI tools.
  • □Ask the agent to separate file evidence from inference.
  • □Inspect proposed edits and run the checks yourself.
  • □Take responsibility for every result you keep.
