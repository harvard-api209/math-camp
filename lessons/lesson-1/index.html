LEARNING OUTCOMES

Know what you are looking at.

By the end of the meeting, you should be able to open a project, run R code, identify the unit of observation, inspect variables, and ask an agent for an explanation without surrendering the question.

  1. 01Distinguish R, RStudio, Quarto, and the coding agent.
  2. 02Describe one row and one column in plain language.
  3. 03Use glimpse(), count(), and summary() to inspect a dataset.
  4. 04Recognize missing values and implausible ranges.
  5. 05Ask Codex or Claude Code to explain a bounded piece of code.

THE TOOLCHAIN

Four tools, four different jobs.

ToolWhat it doesWhat it does not decide
RExecutes instructions and computes results.Whether the question is meaningful.
RStudioProvides an editor, console, files, plots, and help.Whether the code is substantively correct.
QuartoCombines narrative, code, results, and slides.Whether a claim follows from the evidence.
Codex / Claude CodeReads project context and proposes or edits code.Whether its output should be trusted.
NO-AGENT CHECKPOINT

Run the starter script, change one country code, and predict the result before using an agent. This small step makes the boundary between R and AI visible.

AGENT PASS

Ask for an explanation, not a rescue.

STARTER PROMPT
Goal: Explain what the selected R code does to a student who is new to programming.
Context: Read the script and the dataset dictionary in this project.
Constraints: Do not edit files. Explain each object and function in plain language. Flag anything you cannot infer from the files.
Done when: I can state the unit of observation, the row count, and the purpose of each line.
  • □Did the agent identify a country-year as one observation?
  • □Did it distinguish missing data from zero?
  • □Can you verify its row count by running code?
  • □What did the agent assume that the file did not establish?
