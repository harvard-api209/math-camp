\begin{frame}{Re-rank the five capabilities}
  \begin{columns}[T,onlytextwidth]
    \column{0.76\textwidth}
      \textbf{Slido ranking}

      A coding agent produced a figure and paragraph for a ministerial briefing
      due in 30 minutes. Rank the same five capabilities again:
      \begin{enumerate}
        \item Frame a policy question with a decision at stake.
        \item Exercise statistical judgment.
        \item Steward data and provenance.
        \item Read, modify, and explain code.
        \item Supervise and verify an agent.
      \end{enumerate}

      \vspace{0.35em}
      Compare this ranking with your opening response. Which analytical move
      changed your ordering?
    \column{0.20\textwidth}
      \input{slido-join}
  \end{columns}
\end{frame}

\begin{frame}{Lab 3 has four exercises before Codex}
  During the next hour, each student will:
  \begin{enumerate}
    \item select and describe one documented region;
    \item construct parallel all-countries and regional briefing tables;
    \item construct comparable all-countries and regional figures;
    \item write an interpretation and save the R file.
  \end{enumerate}

  \vfill
  After Exercise 4, Codex reads the same saved file, fits one pooled model for
  each sample, and proposes claims. You verify one material statement before
  deciding whether to accept, revise, or reject it.
\end{frame}
