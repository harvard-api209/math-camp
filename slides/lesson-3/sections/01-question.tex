\section{Capabilities for a changing labor market}
\subsection{Define the policy task}

\begin{frame}{Capabilities for policy analysis in a changing labor market}
  Employers expect roughly \alert{39\% of workers' core skills} to change by
  2030. Analytical thinking remains the most frequently reported core skill,
  while AI, big data, and digital skills are among the fastest-growing areas.

  \vspace{0.6em}
  OECD vacancy evidence also shows strong demand in AI-exposed occupations for:
  \begin{itemize}
    \item management and business-process skills;
    \item cognitive, social, and communication skills;
    \item digital fluency across changing tools.
  \end{itemize}

  \vfill
  Coding agents draft code, inspect files, and run checks. Analysts remain
  responsible for the policy question, empirical design, and recommendation
  \citep{wef2025futurejobs,green2024skills,oecd2026skills}.
\end{frame}

\begin{frame}{Four terms for the agent workflow}
  \begin{columns}[T,onlytextwidth]
    \column{0.48\textwidth}
      \textbf{Model}\par
      Parameters that receive context and generate tokens. Model choice affects
      capability, speed, and cost.

      \vspace{0.9em}
      \textbf{Reasoning}\par
      Additional model computation before an answer or tool request. Higher
      effort can help with difficult comparisons and consumes more output tokens.
    \column{0.48\textwidth}
      \textbf{Agent}\par
      A model operating through a harness with context, tools, permissions, and
      a continuing session. Codex is an agent.

      \vspace{0.9em}
      \textbf{Skill}\par
      Reusable task instructions and resources loaded when relevant. A skill
      supplies a procedure and checks; model parameters remain unchanged.
  \end{columns}

  \vfill
  \fnote{Adapted from Pocock's AI Coding Dictionary entries on models, agents,
  harnesses, tools, effort, and skills \citep{pocock2026dictionary}.}
\end{frame}

\begin{frame}{Analogy}

\textbf{A useful analogy}:

\begin{itemize}
  \item Model = which person you hire.
  \item Reasoning ability = how capable that person is.
  \item Effort = how long and carefully they work.
  \item Speed = how soon you receive the result.
\end{itemize}

\end{frame}

\begin{frame}{The policy director's question}
  \begin{block}{Briefing request}
    Across 2000--2022, how did national income and under-five mortality move
    together across economies and within economies? Which associations does
    this evidence support in a briefing to a policy director?
  \end{block}

  \vspace{0.5em}
  The analysis must distinguish:
  \begin{itemize}
    \item an \textbf{economy--year} from an economy;
    \item differences \textbf{between economies} from changes \textbf{within economies};
    \item a descriptive association from an intervention effect;
    \item a pooled association from a within-economy association.
  \end{itemize}

  \vfill
  The policy question determines the relevant comparison.
\end{frame}
