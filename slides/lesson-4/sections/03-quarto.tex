\section{From script to report}

\begin{frame}{Why use a rendered report?}
A script can compute a result. A policy brief must also tell the reader:
\begin{itemize}
\item the question and decision context;
\item the source, sample, unit, and period;
\item how the table and figure were produced;
\item what the evidence supports; and
\item what remains uncertain.
\end{itemize}
\vspace{0.3cm}
Quarto keeps the prose, code, and generated output in one document.
\end{frame}

\end{lstlisting}
The YAML controls the document. Markdown supplies prose and headings. R chunks compute the evidence.
\end{frame}

\begin{frame}{Rendering checks the document from the beginning}
When you click Render, Quarto starts a fresh R session and executes the chunks in order.
\begin{itemize}
\item An object created only in the Console is unavailable.
\item A missing package or file path becomes visible.
\item A table or figure must be generated by code in the document.
\item A successful render produces a portable record of the analysis.
\end{itemize}
\end{frame}

\begin{frame}{A draft brief mixes two comparisons}
A draft brief contains:
\begin{itemize}
\item a table restricted to 2022;
\item a figure pooling all years from 2000 to 2022; and
\item the sentence, ``Higher income reduces under-five mortality.''
\end{itemize}
\vspace{0.25cm}
\textbf{The evidence chain breaks in two places:}
\begin{enumerate}
\item The table and figure describe different periods and samples.
\item The sentence turns a descriptive association into a causal claim.
\end{enumerate}
\end{frame}

\begin{frame}{The smallest defensible repair}
\begin{enumerate}
\item Restrict both the table and figure to the same 2022 sample.
\item Describe the relationship as an association and report its variation.
\end{enumerate}
\vspace{0.3cm}
\textbf{Revised finding:}
\vspace{0.15cm}

``Among economies in 2022, higher GDP per capita is associated with lower under-five mortality. Mortality still varies substantially among economies at similar income levels.''
\end{frame}

\begin{frame}{A good prompt specifies the analysis}
\small
\textbf{Example prompt for the health brief}
\vspace{0.15cm}

\begin{quote}
Read \texttt{health-brief.qmd} and the 2022 health CSV it imports. Complete the brief for this question: How is GDP per capita associated with under-five mortality, and how does the pattern differ by current income group?

Use one row per economy. Create an income-group table reporting the number of economies and the minimum, mean, median, and maximum under-five mortality. Then create a scatterplot with GDP per capita (PPP) on the x-axis, under-five mortality on the y-axis, and income group mapped to color. Use \texttt{geom\_point(alpha = 0.75)}, a log-scaled x-axis, informative axis labels with units, a readable legend, and \texttt{theme\_minimal()}.

Do not fit a model or make a causal claim. Render the HTML brief and report the sample size, aesthetic mappings, and any warnings. Stop if a required variable is absent.
\end{quote}
\end{frame}
