\begin{frame}{Checkpoint 3: plan one track}
Choose a question. Before writing code, state:
\begin{enumerate}
\item the row unit and period;
\item the variables required;
\item the function sequence for the table;
\item the variables mapped to the figure;
\item one claim the evidence could support; and
\item one claim it could not support.
\end{enumerate}
\vfill
\centering\textbf{2 minutes discuss \(\longrightarrow\) 2 minutes share}
\end{frame}
