\section{From Lesson 1 to Lab 1}
\subsection{What we keep}

\begin{frame}{What we learned in Lesson 1}
  \begin{itemize}
    \item Choose the task before choosing the tool.
    \item Keep understanding close to the speed of production.
    \item Match agent autonomy to risk and verifiability.
    \item Define completion evidence before execution.
    \item Keep the question, interpretation, and responsibility with the person.
  \end{itemize}

  \vfill
  We will reuse this supervision structure during the next lessons as the code
  changes.
\end{frame}

\begin{frame}{Lab 1 is an installation clinic}
  \vfill
  \begin{center}
    {\LARGE\color{crimson}The data exercise begins after every laptop passes the readiness gate.}

    \vspace{0.8em}
    A laptop is ready when the setup check is green. A red result leaves with
    the exact error, one repair step, and a named person for follow-up.
  \end{center}
  \vfill
\end{frame}

\begin{frame}[fragile]{The readiness gate}
  Open the Terminal tab in RStudio and run:

\begin{lstlisting}
Rscript code/check_setup.R --codex-confirmed
\end{lstlisting}

  The checker verifies:
  \begin{itemize}
    \item the course project and the R version;
    \item required R packages;
    \item Quarto;
    \item the frozen teaching data;
    \item Codex access to the same project.
  \end{itemize}
\end{frame}
