\section{From a checked table to a defensible handoff}
\subsection{Review the claim, not just the code}

\begin{frame}{Goal for the live demonstration}
  We began with a policy question and built one economy--year table. The final
  task is to decide what that completed object can support \alert{now}---before
  anyone makes a plot or estimates a model.

  \vspace{0.6em}
  \begin{block}{The draft statement we have been asked to review}
    ``Across 217 economies from 2000 to 2022, higher income reduced under-five
    mortality.''
  \end{block}

  \vfill
  We will ask Codex to audit that sentence against the same files we created,
  then decide whether its revision deserves to enter a briefing.
\end{frame}

\begin{frame}[fragile]{Step 1: establish the evidence ourselves}
  Rebuild the table and independently inspect the saved object:

\begin{lstlisting}
Rscript code/02-build-analysis.R
Rscript code/02-verify-analysis.R
\end{lstlisting}

  \begin{description}
    \item[Analysis table] Economy--year records available for later plots and models.
    \item[Build record] Included and excluded rows, economies, years,
      missingness, ranges, and key status.
    \item[Verifier] A separate process that checks the saved table against its
      stated construction rules.
  \end{description}

  \vfill
  Passing checks establish a usable table. They do not establish the substantive
  relationship in the opening policy question.
\end{frame}

\begin{frame}{Step 2: separate three kinds of statements}
  The draft sentence mixes claims that require different evidence:

  \begin{description}
    \item[Already documented] The analytical sample size, period, unit, key,
      and variable definitions.
    \item[Not yet calculated] The direction, size, and uncertainty of the
      association between income and mortality.
    \item[Not supported by this design] A causal claim that changing national
      income reduced mortality.
  \end{description}

  \vfill
  The live demonstration asks the agent to keep these categories separate. We
  are not asking it to alter the table or verifier.
\end{frame}

\begin{frame}[fragile]{Step 3: give Codex one bounded review task}
  Begin with the decision, artifacts, and draft statement:

\begin{lstlisting}[basicstyle=\ttfamily\scriptsize]
We need to decide whether a draft sentence is ready for a policy
briefing. Review the sentence against the checked Lesson 2 artifacts.

Draft: "Across 217 economies from 2000 to 2022, higher income
reduced under-five mortality."

Read:
- outputs/02-health-build-record.csv
- outputs/02-health-analysis.csv
- data/documentation/indicator-dictionary.csv
- code/02-build-analysis.R
- code/02-verify-analysis.R
\end{lstlisting}

  \vfill
  The prompt points to the source of truth instead of asking for a general
  opinion about whether the sentence sounds plausible.
\end{frame}

\begin{frame}[fragile]{Step 3 continued: require an auditable answer}
  Complete the same prompt with limits and a response contract:

\begin{lstlisting}[basicstyle=\ttfamily\scriptsize]
Work in read-only mode. Do not edit files, browse the web, or run a
new statistical model. For each part of the draft, classify it as:
(a) supported by an artifact, (b) not yet calculated, or
(c) not supported by this descriptive design.

Cite the exact file and value used for every supported statement.
Then write a two-sentence handoff note that states what table we
built and what analysis must happen next. Separate facts found in
files from your inferences. If an item cannot be verified, say so.
\end{lstlisting}

  \vfill
  In RStudio, print \texttt{bounded\_agent\_request} to copy the complete
  prompt into Codex as one message.
\end{frame}

\begin{frame}{Step 4: inspect the answer against the artifacts}
  Do not accept the prose because it is fluent. Check:
  \begin{enumerate}
    \item Did it use 188 analytical-sample economies rather than 217 source economies?
    \item Did it distinguish 4,296 retained rows from 695 excluded rows?
    \item Did it avoid claiming that every economy is observed in every year?
    \item Did it reserve the association for the next analytical step?
    \item Did it reject causal language rather than merely soften the verb?
  \end{enumerate}

  \vfill
  The class checks the agent's trace against the table plan and build record.
\end{frame}

\begin{frame}{Final synthesis: write the handoff}
  Classify each part of the draft as \textbf{supported},
  \textbf{not yet calculated}, or \textbf{not supported by this design}. Then
  write two sentences for the analyst who will make the first plot.

  \vspace{0.5em}
  Your handoff must state:
  \begin{enumerate}
    \item what one row represents and how large the analytical sample is;
    \item which rows were excluded by the table plan;
    \item what relationship still needs to be examined;
    \item which causal conclusion remains outside the evidence.
  \end{enumerate}

  \vfill
  \centering
  \textbf{2 minutes discuss}\qquad$\longrightarrow$\qquad
  \textbf{2 minutes share}
\end{frame}

\begin{frame}{A defensible handoff at the end of Lesson 2}
  \begin{block}{Supported by the checked artifacts}
    We constructed a table of 4,296 economy--year observations from 188
    economies between 2000 and 2022, retaining records with observed
    under-five mortality and observed positive GDP per capita, PPP. The table
    excludes 695 source rows and has one row per economy--year.
  \end{block}

  \begin{block}{What happens next}
    The table is ready for a descriptive comparison of income and mortality.
    We have not yet estimated that association, and this table alone cannot
    establish that a change in income causes mortality to change.
  \end{block}

  \vfill
  This is the handoff from Lesson 2 to Lesson 3: from a checked object to a
  carefully bounded analysis of patterns.
\end{frame}

\begin{frame}{Decisions the analyst keeps}
  \begin{itemize}
    \item The meaning of one row.
    \item The population represented by a filter.
    \item Whether a transformation fits the policy question.
    \item Whether current metadata can be interpreted historically.
    \item Whether missing coverage weakens the comparison.
    \item Whether a proposed sentence stays inside the available evidence.
  \end{itemize}

  \vfill
  The agent can organize and challenge evidence. The analyst owns the claim.
\end{frame}

\begin{frame}{Updating public data is an extension}
  Extending one indicator beyond 2022 can be useful. It also adds:
  \begin{itemize}
    \item an internet and API dependency;
    \item retrieval dates and version changes;
    \item possible revisions to earlier years;
    \item new metadata and comparability questions.
  \end{itemize}

  \vfill
  First build and explain the frozen table. Then extend it as a separate,
  documented investigation.
\end{frame}

\begin{frame}{What we learned in Lesson 2}
  \begin{itemize}
    \item Define the table we need before using data verbs.
    \item Every verb should have a reason and a check.
    \item A join must preserve the intended key and unit.
    \item The analysis table should rebuild from a protected source.
    \item A separate verifier should inspect the saved object.
    \item A bounded agent review can test whether prose follows from artifacts.
    \item A checked table is the beginning of analysis, not its conclusion.
  \end{itemize}
\end{frame}
