FROZEN BASELINE

Begin from a common reference point.

The default dataset is a teaching snapshot built from the World Bank World Development Indicators API. It reduces setup friction while retaining real missingness, revisions, uneven time coverage, and policy-relevant variables.

FileShapeUse

Indicator dictionaryOne indicator per row.Tracks, official names, units, definitions, sources, and retrieval dates.

FROZEN DOES NOT MEAN TRUE FOREVER

The 2022 endpoint gives the class a shared baseline. Official historical values may later be revised. The update lab treats those revisions as something to detect and document.

Classification warning. income_level_current and lending_type_current describe World Bank metadata available when the teaching snapshot was assembled. They are not historical classifications. The project joins countries by iso3c, not by names that may differ across sources.

COMMON CORE, OPTIONAL PATHS

Begin together, then choose a complete recipe.

Everyone first runs the health example so the room shares one sample, one model, and one vocabulary for checking work. The four optional paths are not interchangeable versions of that model. Each question requires its own unit, sample, comparison, and limitation; use the complete scripts in code/tracks/.

  1. 01Health: complete country-years, 2000–2022. Compare logged income and under-five mortality while describing current income classifications honestly.
  2. 02Gender: complete country observations in 2022. Compare female secondary enrollment and adolescent fertility in a cross-section, noting missing coverage and regional context.
  3. 03Access: country trajectories at least ten years long. Compare annual change in electricity and internet access using each country’s actual elapsed years.
  4. 04Climate: countries in the latest common complete year. Compare renewable electricity and carbon intensity while showing per-capita growth; the frozen file’s latest complete common year is 2021, not 2022.

These are descriptive and associational questions. The dataset alone does not identify causal effects.

OPTIONAL HIGH CEILING

Extend one indicator safely.

Students who want a larger challenge can supervise an agent-assisted request to the official API. Run Rscript code/04-update-indicator.R SH.DYN.MORT under5_mortality. The script writes a retrieval-dated file under data/updates/; the maintainer build refuses to overwrite the frozen baseline without an explicit environment variable.
