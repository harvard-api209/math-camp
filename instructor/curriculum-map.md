## Repeated learning routine

1. **State the task.** Name the question and the object you need.
2. **Predict.** Say what should change before running code or asking for help.
3. **Work in a small step.** Read or modify code that can be inspected.
4. **Ask narrowly.** Give the agent a goal, context, permission boundary, and
   visible completion check.
5. **Check and explain.** Inspect the files and output, then decide what to keep.

## Low floor and high ceiling

- **Low floor:** one complete project, frozen data, exact setup commands,
  supplied R scaffolds, and visible checks.
- **Common path:** every student uses the same country-year file and first
  completes the health example.
- **High ceiling:** reusable checks, another policy question, or a separate
  public-data update.
- **Assessment:** formative only; there is no graded or group submission.
