# Math Camp 2026

Standalone first-pass website inspired by the technical-manual layout and motion language of Making Software.

## Preview

From this directory:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Files

- `index.html`: page structure and draft Math Camp content
- `styles.css`: layout, typography, responsive behavior, and diagram styling
- `script.js`: canvas figures, scroll reveals, active outline, and mobile navigation
- `assets/fonts/`: self-hosted Departure Mono font and license
