How to think with data.

A field guide to observations, comparisons, models, and reproducible quantitative work.

Math camp is not a speed test. It is a short manual for learning how quantitative work is assembled from observations, choices, comparisons, and code.

We will begin with the shape of a dataset, move through visualization and modeling, and finish with a workflow that another person can inspect and run. No prior fluency is assumed.

00

INTRODUCTION

Data does not arrive with its meaning attached.

A dataset looks rectangular and orderly, but every cell is the result of a decision. Someone chose what to observe, how to measure it, and what to leave out.

Quantitative work begins by reconstructing those decisions. Before calculation, we ask what each row represents, what each variable means, and whether the available comparison matches the policy question.

Code helps us make those choices visible. It does not replace judgment. The goal of math camp is to connect the two.

01

OBSERVATIONS

A row is a claim about what counts as one thing.

A row might represent a person, a school, a municipality, a country-year, or an interview. Changing the unit changes the question.

Suppose one table has a row for each student and another has a row for each classroom. An average computed from the first table gives every student equal weight. An average computed from the second gives every classroom equal weight. Both can be correct, but they describe different populations.

UNIT_OF_ANALYSIS ONE ROW = ONE OBSERVATION

Write this sentence before you write a model.

02

VARIABLES

A variable is a concept translated into values.

Income, learning, trust, and program participation sound concrete until we need to place them in a column.

Measurement makes an abstract idea operational. The variable name should tell us what was measured, while documentation should tell us how, when, and for whom.

Good analysis preserves the distance between the concept and its measurement. We do not treat a proxy as if it were the thing itself.

03

DISTRIBUTIONS

The average is a location, not a complete description.

Two groups can have the same mean and completely different shapes.

A distribution reveals concentration, spread, gaps, and unusual observations. This is why we visualize before modeling. A chart lets us see which features a summary preserves and which features it erases.

Start with the shape. Then decide which summary earns the right to represent it.

04

COMPARISON

A useful difference needs a useful counterfactual.

Description asks what happened. Causal reasoning asks what would have happened otherwise.

That second outcome is not observed for the same person at the same time. We approximate it with another group, another period, or a model.

The credibility of the result depends on the comparison, not the visual polish of the final coefficient.

05

MODELS

A model is a deliberate compression of reality.

A regression line cannot preserve every observation. It preserves a pattern we have chosen to summarize.

The distance between each observation and the fitted value is a residual. Residuals are not merely errors to hide. They show what the model does not explain and help us diagnose where the compression fails.

RMODEL_01
model <- lm(
  outcome ~ program + baseline,
  data = camp_data
)

summary(model)

Read the formula as a sentence: describe the outcome using program status and the baseline measure.

06

WORKFLOW

The path to the result is part of the result.

Reproducibility means that a reader can inspect the source, rerun the transformations, and recover the same output.

  1. IMPORT Keep source files unchanged.

    Record where the data came from and when it was retrieved.

  2. CLEAN Make every transformation explicit.

    Use code for recoding, filtering, joining, and handling missing values.

  3. EXPLORE Look before choosing the model.

    Plot distributions, inspect unusual cases, and test assumptions.

  4. MODEL Connect the method to the question.

    State what the model preserves and what it leaves unexplained.

  5. COMMUNICATE Write the claim at the right level.

    Distinguish description, prediction, association, and causation.
