# Handoff clinic: audit before repair

This miniature project is intentionally unreliable. Do not trust its polished
claim or repair it from memory.

## Your task

1. Predict which dependency will fail on another computer.
2. Run `analysis.R` from a clean R session.
3. Compare the script with `outputs/result.txt`.
4. Record every issue as:
   - observed evidence;
   - why it matters;
   - smallest defensible repair;
   - check proving the repair worked.
5. Repair one issue at a time.

The fixture contains four consequential problems. A fifth stylistic preference
does not count as a failure unless it changes reproducibility or interpretation.

Do not open the instructor key until the room has completed the first audit.
